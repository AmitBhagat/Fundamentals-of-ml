Chapter 123: Policy Gradients

Prerequisite

  • Policy (πθ\pi_\thetaπθ​): A neural network that maps a state sss to a probability of taking action aaa.
  • Return (GGG): The total sum of rewards received in an episode.
  • log⁡\loglog Derivative Trick: The mathematical identity ∇log⁡f(x)=∇f(x)f(x)\nabla \log f(x) = \frac{\nabla f(x)}{f(x)}∇logf(x)=f(x)∇f(x)​.

Analogy

Imagine you are a Football Coach training a new quarterback. You don't know the "Perfect Physics" of how to throw a ball; you just watch the result.

If the quarterback throws a pass and it’s caught (High Return GGG), you blow your whistle and yell "Do exactly that again!" (Increase the probability of that action). If the pass is intercepted (Low Return GGG), you yell "Never do that again!" (Decrease the probability).

Policy Gradients is the math of the Coach's Whistle. We don't try to calculate the "Value" of every single blade of grass on the field. Instead, we just tweak the weights of the "Brain" (the Policy) so that the actions that led to high scores become more likely, and the actions that led to disasters become less likely. It’s pure, calculated trial-and-error.

The Math Link

In Policy Gradients, we want to maximize the expected total reward J(θ)=Eπθ[G]J(\theta) = \mathbb{E}_{\pi_\theta}[G]J(θ)=Eπθ​​[G].

The Policy Gradient Theorem: ∇θJ(θ)=Eπθ[∇θlog⁡πθ(a∣s)⋅G]\nabla_\theta J(\theta) = \mathbb{E}_{\pi_\theta} \left[ \nabla_\theta \log \pi_\theta(a | s) \cdot G \right]∇θ​J(θ)=Eπθ​​[∇θ​logπθ​(a∣s)⋅G]

The Logic:

  1. πθ(a∣s)\pi_\theta(a | s)πθ​(a∣s): The probability of picking action aaa.
  2. ∇θlog⁡πθ\nabla_\theta \log \pi_\theta∇θ​logπθ​: The direction in weight-space that makes action aaa more likely.
  3. GGG (The Scalar): The "Volume" of the whistle. If GGG is positive and large, we take a huge step in that direction. If GGG is negative (or smaller than average), we move away.
  4. The Expectation (E\mathbb{E}E): Since we can't play every possible game, we sample many episodes and average the gradients.

THE INTUITION Policy Gradients are "Stochastic Hill Climbing." We are in a foggy landscape of possible behaviors. We take a step, and if the "Altitude" (Total Reward) increases, we keep moving that way. We don't need a map (Model of the environment); we just need to feel the ground.

Let's Run the Numbers

Example 1: Updating a 2-Action Policy

An agent is in a state where it can go Left (a1a_1a1​) or Right (a2a_2a2​).

  • Initial probabilities: π(a1)=0.5,π(a2)=0.5\pi(a_1) = 0.5, \pi(a_2) = 0.5π(a1​)=0.5,π(a2​)=0.5.
  • The agent picks Right (a2a_2a2​) and eventually wins G=10G = 10G=10 points.

Calculation: We want to update the parameter θ\thetaθ associated with Action 2.

  1. The "Score" is ∇θlog⁡π(a2)\nabla_\theta \log \pi(a_2)∇θ​logπ(a2​).
  2. If we use a simple linear model where π(a2)=eθ2eθ1+eθ2\pi(a_2) = \frac{e^{\theta_2}}{e^{\theta_1} + e^{\theta_2}}π(a2​)=eθ1​+eθ2​eθ2​​, the derivative ∇θ2log⁡π(a2)\nabla_{\theta_2} \log \pi(a_2)∇θ2​​logπ(a2​) is (1−π(a2))=0.5(1 - \pi(a_2)) = 0.5(1−π(a2​))=0.5.
  3. Update: Δθ2=Learning Rate×(0.5×10)=α×5\Delta \theta_2 = \text{Learning Rate} \times (0.5 \times 10) = \alpha \times 5Δθ2​=Learning Rate×(0.5×10)=α×5.

The Story: Because the agent won, we "Pushed" the weights of the Right action. Next time the agent is in this state, π(a2)\pi(a_2)π(a2​) might be 0.60.60.6. The agent is literally "Learning to win."

Example 2: The "Credit Assignment" Problem

Suppose the agent took 100 actions. Action 5 was a brilliant move, but Action 99 was a mistake that almost lost the game. However, the final score was G=50G=50G=50 (A win).

Calculation: Every single action a1…a100a_1 \dots a_{100}a1​…a100​ will be multiplied by the same G=50G=50G=50 in the basic REINFORCE algorithm. ∇θ≈∑t=1100∇log⁡π(at∣st)⋅50\nabla \theta \approx \sum_{t=1}^{100} \nabla \log \pi(a_t | s_t) \cdot 50∇θ≈∑t=1100​∇logπ(at​∣st​)⋅50

The Story: This is the high variance of Policy Gradients. Even the "bad" action (99) gets rewarded because the "good" action (5) carried the team. This is why Policy Gradients require millions of episodes to "average out" the luck.

Example 3: Baseline Subtraction (Reducing Variance)

To fix Example 2, we subtract a Baseline b(s)b(s)b(s) (the average reward we expect from this state). ∇θJ(θ)=E[∇θlog⁡πθ⋅(G−b(s))]\nabla_\theta J(\theta) = \mathbb{E} [ \nabla_\theta \log \pi_\theta \cdot (G - b(s)) ]∇θ​J(θ)=E[∇θ​logπθ​⋅(G−b(s))]

Calculation: If the average reward for this state is b(s)=45b(s) = 45b(s)=45, and the agent gets G=50G=50G=50:

  • "Advantage" = 50−45=550 - 45 = 550−45=5. If the agent gets G=40G=40G=40 (Still a win, but worse than average):
  • "Advantage" = 40−45=−540 - 45 = -540−45=−5.

The Story: Now, even if the agent "wins," we only reward it if it won better than usual. This prevents the agent from getting "complacent" with mediocre strategies.

CRITICAL TECHNICAL INSIGHT: The Entropy Trap If a Policy Gradient agent finds a "safe" way to win early on, it might stop exploring. Its probabilities will become 1.01.01.0 for the safe action and 0.00.00.0 for everything else. This is Premature Convergence. To fix this, we add an Entropy Bonus to the loss function, which essentially "pays" the agent a small reward just for being uncertain and trying new things.

ML Applications

  1. ChatGPT / RLHF: Using PPO (Proximal Policy Optimization) to tweak the "Policy" of a language model so it speaks in a way humans find helpful.
  2. Robotic Control: Learning how to walk or grasp objects where the "Dynamics" are too complex for a standard controller.
  3. AlphaStar: Beating professional players at StarCraft II by using policy gradients to manage thousands of units simultaneously.
  4. Recommendation Systems: Optimizing for "Long-term Engagement" (Total Watch Time) rather than just a single click.
  5. Chemical Synthesis: Discovering new drugs by treating the addition of atoms as "Actions" and the stability of the molecule as the "Reward."

Debugging Tip: If your Policy Gradient agent's performance is wildly oscillating, your Learning Rate is too high. Because the "Whistle" (G)(G)(G) can be very loud, a single lucky episode can yank the weights so far that the agent "forgets" everything it learned previously. Use PPO to clip the updates and keep the training stable!
